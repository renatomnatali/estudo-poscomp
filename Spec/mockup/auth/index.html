Telas de conta

Cinco telas públicas de autenticação do aprovado.xyz. Cada tela abre no estado padrão; os demais estados abrem com ?estado=… nos links abaixo.

/entrar

Entrar

entrar.html

  • padrão formulário limpo com widget anti-bot
  • erro 401 — credenciais inválidas (resposta genérica)
  • não verificado 403 — instrução + reenvio do link
  • reenviado confirmação do reenvio da verificação
  • limite 429 — muitas tentativas, aguarde
  • carregando submit em andamento
/cadastro

Criar conta

cadastro.html

  • padrão formulário com requisitos de senha vivos
  • erro de senha 400 — política fora do padrão
  • sucesso "verifique seu e-mail", sem login automático
  • já cadastrado conta existe — entrar ou recuperar
  • limite 429 — muitas tentativas
  • carregando submit em andamento
/verificar-email

Verificar e-mail

verificar-email.html

  • verificando consumindo o token da URL (padrão)
  • confirmado verificado — vai pro login em 3s
  • inválido link inválido/expirado + reenvio
  • reenviado resposta genérica após pedir reenvio (no próprio card)
/esqueci-senha

Esqueci a senha

esqueci-senha.html

  • padrão formulário de e-mail
  • enviado resposta genérica — sem oráculo de enumeração
  • limite 429 — muitas tentativas
  • carregando submit em andamento
/redefinir-senha

Criar nova senha

redefinir-senha.html

  • padrão token válido — política visível + confirmação
  • link inválido unificado — solicitar novo
  • erro de política 400 — senha fora do padrão
  • não coincidem confirmação diverge (vivo ao digitar)
  • token expirou falha só no submit (defesa em profundidade)
  • sucesso senha trocada — vai pro login em 3s
  • carregando submit em andamento

Sistema visual: DS aprovado (Geist + Geist Mono, tokens de Spec/aprovado_ design system/colors_and_type.css) — telas de conta são públicas, contexto da landing. Botões de ação semi-retangulares (12px, nunca pill); chips de requisito são pill + mono, semântica distinta de botão. Vazio não se aplica (nenhuma tela lista dados). Visitante já com sessão que abre /entrar é levado ao /dashboard no produto (não simulado aqui).
